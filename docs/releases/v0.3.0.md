# PartyUp 0.3.0

Исправлены все девять issues #1–#9.

- Организатор может изменить дату и время в существующей встрече. Чат и участники сохраняются, гости получают уведомление и подтверждают новое время заново. Старые будильники снимаются, новые срабатывают после подтверждения. Конкурирующие изменения времени защищены проверкой версии.
- Лупа в поле поиска выровнена по центру.
- Создание встречи упрощено: игра, дата, начало, друзья. Отдельные поля названия и описания убраны; детали обсуждаются в чате.
- Время окончания и фиксированная двухчасовая длительность убраны. После начала встреча попадает в прошедшие; чат остаётся доступен.
- Добавлен поиск по каталогу магазина Steam с выбором игры и обложкой высокого разрешения. Ключ Steam не нужен. Ручной ввод доступен для других игр и при недоступности Steam; доступность результатов зависит от каталога Steam.
- В настройках можно изменить имя, загрузить или удалить аватарку, сменить пароль с проверкой текущего. После смены пароля другие сеансы входа завершаются.
- В календаре появился сохраняемый переключатель скрытия отменённых встреч и собственных отказов.
- В настройках доступен масштаб 100–200%, который сохраняется для аккаунта на устройстве. Виджет сохраняет собственный масштаб.
- Список уведомлений можно очистить с подтверждением. Встречи и приглашения сохраняются; счётчик непрочитанных обнуляется.

## Файлы

- `PartyUp-0.3.0-Windows.exe` — portable Windows 10/11 x64, без установки Node.js. Сборка не подписана сертификатом издателя.
- `PartyUp-0.3.0-Android.apk` — подписанный release-установщик для Android 7.0+ (API 24), версия 0.3.0, код 3. Установка напрямую из файла; потребуется разрешить установку приложений из выбранного источника. Укажите адрес общего сервера после запуска.
- `PartyUp-0.3.0-Server.zip` — общий сервер Node.js 24+, шаблоны настроек и инструкция запуска/обновления. Без пользовательской базы, секретов и демо-аккаунтов.
- `SHA256SUMS.txt` — контрольные суммы Windows, APK и серверного архива.
- Исходники iOS обновлены и синхронизированы. IPA в этот релиз не входит.

## Обновление

Обновить **сервер и клиенты до 0.3.0**. Сначала сделать резервную копию SQLite, остановить сервер, заменить исходники и запустить сервер с прежними `.env` и `DATA_DIR`. База обновляется автоматически; аккаунты, встречи, сообщения и настройки сохраняются. Подробности — в `SERVER.md` внутри серверного архива.

На Windows закрыть старую версию через трей → «Завершить работу», затем запустить новый `.exe`. Адрес сервера и локальные настройки сохраняются. Если включён автозапуск, повторно включить его для нового пути файла.
