# PartyUp 0.3.1

Исправлены issues [#10](https://github.com/vowanchik/DegradCalendar/issues/10), [#11](https://github.com/vowanchik/DegradCalendar/issues/11) и [#12](https://github.com/vowanchik/DegradCalendar/issues/12).

- **Скрытый сервер Windows (#10).** Двойной щелчок по `Start-Server.vbs` запускает API без консоли, `Stop-Server.vbs` останавливает его. Есть PowerShell-команды Start / Stop / Status, логи, защита от повторного запуска и остановки чужого PID. В `SERVER.md` описан автозапуск через Планировщик без входа пользователя.
- **Многострочный чат (#11).** Поле ввода переносит длинный текст и растёт до 180 px, затем прокручивается. Enter отправляет сообщение, Shift+Enter добавляет строку. После отправки поле возвращается к исходной высоте. Работает и на узком экране.
- **Согласие всей команды (#12).** Будильник создаётся только если все приглашённые согласились играть. Ожидающий ответа или отказавшийся участник блокирует его для всей команды. Проверка повторяется перед отправкой мобильного push, включая повторные попытки. Windows также проверяет состав команды перед показом напоминания. Личные интервалы, отключение и дедупликация сохраняются; после переноса встречи нужно повторное согласие всех гостей.
- **Инструкция по мобильным уведомлениям.** В [MOBILE-PUSH.md](https://github.com/vowanchik/DegradCalendar/blob/v0.3.1/docs/MOBILE-PUSH.md) — настройка Firebase на сервере, сборка Android, APNs/iPhone, Docker, включение push на телефоне и проверка с заблокированным экраном. Копия входит в серверный ZIP.

## Файлы

- `PartyUp-0.3.1-Windows.exe` — portable Windows 10/11 x64, без Node.js, без подписи издателя.
- `PartyUp-0.3.1-Android.apk` — подписанный release APK для Android 7.0+, versionCode 4; ключ подписи тот же, что у 0.3.0. **Firebase в готовом APK не настроен**: фоновые push требуют своего проекта и пересборки по инструкции.
- `PartyUp-0.3.1-Server.zip` — Node.js 24+, исходники API, шаблоны `.env`, скрытый запуск Windows, `SERVER.md` и `MOBILE-PUSH.md`. Без базы пользователей, секретов и демо-аккаунтов.
- `SHA256SUMS.txt` — SHA-256 трёх файлов выше.

Исходники iOS обновлены до 0.3.1 (build 4) и синхронизированы. Готового IPA нет.

## Обновление

Обновите **сервер и клиенты до 0.3.1**. Сначала сделайте согласованную резервную копию: `node --env-file=.env scripts/backup.mjs`. Остановите старый API, замените исходники и скрипты, сохраните прежние `.env`, `DATA_DIR`, базу и секреты Firebase. База 0.3.0 не требует новой миграции; аккаунты, встречи и чат сохраняются. После запуска проверьте `/api/health`. Полные шаги — в `SERVER.md` внутри архива.

Старую Windows-версию закройте через трей → «Завершить работу», затем запустите новый EXE. При переносе portable-файла повторно включите автозапуск. Android APK устанавливается поверх официальной версии с тем же ключом; для собственной Firebase-сборки нужен её исходный ключ подписи либо удаление прежнего приложения перед первой установкой.

Проверены ожидание всей команды, отказ/повторное принятие, личные интервалы и отключение будильника, дедупликация, блокирование уже поставленного push после изменения ответа и после ошибки транспорта; многострочный чат на обычном и узком экране.

Android: release-сборка, unit-тесты, lint, проверка подписи, выравнивания и метаданных (package `com.partyup.app`, versionCode 4, minSdk 24, targetSdk 36). SHA-256 сертификата подписи: `a4d46bb9b914de93d0d52a80b5c04698d11cdcba9c9b1d9675380d3f279d21bb`; закрытый ключ и пароль не включены в Git или релиз.

Windows: готовый portable EXE запущен с отдельным профилем; проверены загрузка актуального production-бандла и нативного моста.
